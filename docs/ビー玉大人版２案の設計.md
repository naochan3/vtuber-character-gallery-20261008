# ビー玉の大人版２案

同一人物の23歳の大人版。01と02の衣装差を保ち、顔・骨格・服の寸法を成人へ調整。髪型４案も比較する。

基準は原案142の人物と、かたち05の外見と白いスポーツインナー。

## 01 丸ジョガーの大人版

01の元の丸いジョガーショートパンツを成人用に仕立て直す。丸みとゆとり、白い波の側面切り替え、裾の軽い絞りを維持。大人の体格に自然な普通の太もも丈、膨らませすぎず、元の丸いシルエットが残る。

透明ミニポーチ、生成りのメモ帳、右手首の小粒ビー玉

ブレスレット：小粒の連珠。

## 02 コンパクトパンツの大人版

02のコンパクトなショートパンツを成人用に仕立て直す。01よりすっきりした身幅と少し短めの丈、丸みのあるゆるい裾、白い側面の波形と細い透明な裾縁を維持。普通のスポーツショーツとして自然な丈。

透明ミニポーチ、生成りのメモ帳、右手首の小粒ビー玉

ブレスレット：小粒の連珠。
