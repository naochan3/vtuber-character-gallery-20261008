# ビー玉・白い内側と襟・パンツ３案

原案142の人物を維持する。最新の条件は、内側を白い不透明な袖なし丸首シャツへ統一すること、外Ｔの襟を内側より低くゆるくしないこと、パンツを上の渦と一体の可愛いスポーツデザインへ整えること。

袖は腕より広く、腕の肌色と輪郭、布と腕の間の空間が淡い水青越しに見える。身頃の下は白い不透明な日常の服。ショーツ本体は不透明で、裾だけ細い水青の帯を使う。フリルやリボンではなく、白・水青・少量の青紫、丸いポケットと曲線で女の子らしい柔らかい輪郭を作る。

## 1 水青の波ライン

- 服：水青の薄い渦Ｔ、白い袖なし丸首インナー、水青ショーツと白い波の切り替え・薄い裾帯。
- 設計意図：白い内側とそろった襟、上の渦に呼応する白い波のパンツで一体感を作る。
- 動きの設計：広い薄い袖と、波形の裾帯とポーチのストラップが少し遅れて揺れる。
- 配色：水青・白・濃青・青紫・銀灰。

## 2 白い丸ポケット

- 服：水青の薄い渦Ｔ、白い袖なし丸首インナー、白いショーツと水青の丸いポケット・薄い裾帯。
- 設計意図：白を多く使う明るいボトムに丸い水青の面を置き、ビー玉の形と上の透明感をつなぐ。
- 動きの設計：軽い袖と丸いショーツの裾帯、丸いポーチが控えめに揺れる。
- 配色：白・水青・濃青・青紫・銀灰。

## 3 青紫の丸い裾

- 服：水青の薄い渦Ｔ、白い袖なし丸首インナー、柔らかい青紫の丸いショーツと白い曲線・透明な裾帯。
- 設計意図：原案の青紫を残しつつ、白い曲線と丸い裾で箱形のパンツを軽く柔らかくする。
- 動きの設計：袖が丸く広がって戻り、浅い円弧の裾帯とポーチが追いかける。
- 配色：水青・白・青紫・濃青・銀灰。

今回の動きは設計ラフ。頭部の正本を固定し、腕、薄い袖、白い内側、不透明のショーツ、透明な裾帯を別のパーツとしてモデル化する。
