# 服の遊び心と猫の目４案

改良03を基準に、胴体を不透明にした遊び心のあるスポーツトップスと、横一直線の半目を使わない猫の目を４方向で比較する。

基準は子供版のサイズ比較01。相棒の輪郭・表情・会話の役割を比較する。

## 01 ころんとバブル裾・豆形の横目

細い半目の直線を廃止。両目は横向きのまがったそら豆型で、目尻の端が下がり、内側にごく小さい縦長の瞳。濃紺の輪郭と淡い青白い白目。視線は普段いつも横を向く。上まぶたは少しふくらんだ曲線で、左目だけ少し低い。まつ毛なし。口は短く片側だけ上がり、頬はぽってり。ふてぶてしいのにとぼけて見える。

「それ、いま行くやつ？」と横目で尋ね、しっぽだけ動かす。

衣装：裾が軽く内側へ丸く入る、短すぎないバブルヘムのスポーツトップ。胴体は完全に不透明な淡い水青。肩は丸く落として袖に程よいボリューム。胸から本人左の脇へ大きな弧の生地切り替えが走り、その青紫の弧の端を渦のプリントへつなぐ。中心に丸いロゴを貼るだけにせず、裾の立体的な丸さまで一続きのビー玉の流れに見える。右肩から袖外側の小さい曲面パネルと、二重裾の外側だけが薄い透明青。二重裾の下には同色の不透明布があり肌は見えない。丸首は細い青紫の縁。大きなリボンやベルト無し。

## 02 カーブ重ねのゲームシャツ・しずく目

左右の目は横線の半目ではなく、上が丸く下が細くなる短いしずく形。外側へわずかに傾き、瞳は各目の上寄りに小さく置く。濃青の細い縁と白目がある。上の丸みの半分をふくらんだ青いまぶたが覆う。下まぶたが短い弧になり、ずぶとい眠そうな目にする。左右の瞳の位置は揃え、視線を上向きにして女の子を見上げる。眉は描かず、目の形と小さな横向きの３の口で個性を作る。

地面に座ったまま女の子を見上げて「そっちから話してよ」。

衣装：服の前身頃を２枚のゆるい曲線で重ねたスポーツシャツ。普通の丸首で胸から腰まで完全に不透明。白と水青の広い面を、斜めの大きい丸いカーブで切り替え、右裾の外側に短い半月形の透明青の生地が一枚だけ重なる。下の不透明身頃はパンツのウエストを覆う。袖は不透明な丸いラグラン半袖、片袖の外側にだけ小さい透明な弧を入れる。ビー玉の渦は中央の丸い印刷をやめ、左胸から右裾へ流れる大きな３本の青紫・水青・白のカーブとして組み込む。スポーツ感がありつつ丸く軽いシルエット。

## 03 ころがる裾の二枚重ね・片目だけ起きる猫

普段の顔から左右の開きが違う。本人右目はぽってりした小さな丸い台形で上まぶたはアーチ、縦長の小さい瞳が中にある。左目は短い下向きの曲線１本で閉じ気味。まっすぐな水平線は禁止。興味を持つと閉じた目が先に開く。鼻はごく小さい点、口はむにっとした小さいへの字。まつ毛や眉を使わず、丸い一重のまぶたと眠気で個性。目の大小差は照れや驚きで入れ替わり、単なるウインク笑顔にしない。

片目だけ開けたまま「聞いてる聞いてる」。しっぽはしっかり反応する。

衣装：胴体は不透明で、緩い立体的な切り替えのある白寄り水青のトップス。首元は小さい丸首、袖は丸いゆったり半袖。内側の不透明トップスはウエストまであり、透けない。外側には、右肩から胸の下を大きく回って左の裾に至る短い曲面状の透明青パネルが重なる。透明パネルの下は常に不透明布なので身体は透けず、下の青い渦模様が屈折したように重なって見える。袖の一番外側だけ小さく透ける。外側パネルの端に青紫の太い１本の縁、丸い裾の片側に小さい同色の留め具。服の「ガラスを重ねた」素材遊びを見せ、長いマントや帯は付けない。

## 04 丸い切り替えのプルオーバー・三日月まぶた

目は横に広い三日月型の重いまぶたと、その下にのぞくごく小さい丸い瞳。上端は水平線ではなく、中央が下へ垂れる柔らかい波形。目尻は少し持ち上げ、目頭は低い。白目は少しだけ、全体を青い線で囲みすぎない。左右の間隔を広め、顔の下寄りに置く。鼻と口は目の間の少し下に小さくまとめる。口は一筆のゆるいＳ字のような左右非対称。含み笑いで賢そうだが怠惰、怖さを出さない。

「近道なら、知ってる。」と言いつつ、自分は動かない。

衣装：ごく短い立ち襟と、小さい丸い引き手のハーフジップがある半袖のスポーツプルオーバー。ジップは閉じていて首元は詰まりすぎず広がりすぎない。胴体は完全に不透明な水青、裾はパンツのウエストを覆う。前身頃を大きな丸い青紫と白のカーブで切り替え、右裾が少しだけ丸く重なる。渦は布の切り替えと小さい胸の渦１つで表現する。袖の上半分は不透明で、下半分に丸い透明青のパネル。背中の肩甲骨より下には不透明な布の上へ透明な短い背当てを重ね、内側の模様が見える。肌が見える透明部分は上腕の一部だけ。厚すぎない軽い生地で、作業着や制服ではなく今のスポーツカジュアル。
