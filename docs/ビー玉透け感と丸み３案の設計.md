# ビー玉・透け感と丸みの３案

原案142の顔・髪・瞳・体型と大きい渦を維持する。外布の青い光沢だけでは素材が伝わりにくいため、濃い不透明なＴシャツの輪郭・袖口・縫い目が薄い外布越しに見える構造へ変更する。

肩の角張った大きい形と直線的な袖を抑え、丸い小襟、肩へ落ちる袖、自然に読める腰の位置、短い丸いショーツやキュロットを比較する。顔や髪を別の人物へ変えず、服の印象を柔らかくする。

## 1 透ける渦Ｔと丸いショーツ

- 服：水青の薄い渦Ｔ、濃青の不透明な丸首インナー、青紫の丸いショートパンツ。
- 設計意図：濃いインナーの輪郭を外布越しに読ませ、丸い袖とボトムで軽い女の子の運動着へ整える。
- 動きの設計：薄い外の袖と裾が先に揺れ、不透明な内側の輪郭が動く布越しに見える。
- 配色：水青・濃青・青紫・生成り・銀灰。

## 2 丸い襟のシアーシャツ

- 服：丸い小襟の水青シアーシャツ、濃青の不透明な渦Ｔ、青紫の丸いショートパンツ。
- 設計意図：外のシャツと濃い内Ｔの２枚の輪郭を明確にし、小襟と丸い袖で服の印象を柔らかくする。
- 動きの設計：薄いシャツの前の合わせと丸い袖が揺れ、内Ｔの大きい渦は安定して見える。
- 配色：水青・濃青・青紫・生成り・淡い灰。

## 3 軽い袖とショートキュロット

- 服：不透明な濃青の渦Ｔと水青の軽い外袖、青紫の短いＡラインキュロット。
- 設計意図：身頃の渦を保ち、重なりが見える軽い袖と短いＡラインのボトムで柔らかい輪郭を作る。
- 動きの設計：薄い外袖とキュロットの丸い裾がゆっくり追いかけ、ポーチが小さく揺れる。
- 配色：水青・濃青・青紫・生成り・銀灰。

動きは設計ラフ。モデル化時は頭部の正本を固定し、薄い外布と不透明な内側の衣服を別のパーツとして分割・補完・リギングする。
