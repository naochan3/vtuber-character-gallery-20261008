# ビー玉のパンツサイズ２案

メモ帳を採用し、統合01の立ち絵のパンツを復元した案と、丈・布量をコンパクトにした案を比較。三面図はそれぞれの立ち絵と比率を合わせる。

基準は原案142の人物と、かたち05の外見と白いスポーツインナー。

## 01 元の丸ジョガー

大きい全身正面のパンツは１枚目「統合デザイン01」のふくらみ・裾・太もも丈・横幅をそのまま復元する。２枚目の小さくしたパンツに合わせない。丸みのある元のゆったりしたシルエットがユーザーの好み。三面図のみ、布を余分に大きく描いていた誇張を解消し、この大きい立ち絵の衣服と同じ比率へ合わせる。特に三面図の横幅だけが増えない。腰・肩・裾の比率を揃える。ミニキャラもこの元の丸いパンツを着る。

左腰の透明ミニポーチ、右腰の生成りのメモ帳、右手首の連珠ブレスレット

ブレスレット：小粒の連珠。

## 02 コンパクトなショートパンツ

２枚目のパンツより丈を少し短く（約10％）、身幅を少しコンパクトに（約10％）整えた、自然な日常スポーツ用ショートパンツにする。ゆるい裾で脚との間に空間がある普通の短パン。丸みは少し残すが大きく膨らませない。股上は標準、腰位置はそのまま、きつい服や極端な短さにしない。身体の線や股を強調しない。白い側面の波形、白い調整紐、裾の細い透明な青い縁を維持。大きい立ち絵・三面図・ミニキャラで同じ丈と身幅に統一する。

左腰の透明ミニポーチ、右腰の生成りのメモ帳、右手首の連珠ブレスレット

ブレスレット：小粒の連珠。
