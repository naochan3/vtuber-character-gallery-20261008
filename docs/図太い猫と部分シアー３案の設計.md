# 図太い猫と部分シアー衣装３案

元気な女の子と、図太く面倒くさがりな青いガラス猫。子供版01の髪・顔・丸ジョガーを維持し、Ｔシャツは胴体を不透明にして透けを限定。

基準は子供版のサイズ比較01。相棒の輪郭・表情・会話の役割を比較する。

## 01 歩くのめんどい猫・袖だけシアー

球体を少し横に押したまるい猫。小さな丸三角耳、短い足、太く短いしっぽ。目は横長の半目で上まぶたがほぼ水平。瞳は小さな濃紺の縦楕円、目のハイライトは小さく１つ。口は片側だけわずかに上がる。基本の顔が「めんどくさ…でも話は聞く」の飄々とした表情。いつも腹を床につけていて、歩かずごろんと横転して移動する。驚いても最初は片目しか開けない。

歩きたくない聞き役。自分は転がるだけなのに、女の子の話には妙に鋭い疑問を差し込む。

衣装：Ｔシャツの胴体・肩・首元は不透明な淡い水青の綿生地。胸の大きいビー玉の渦プリントを残す。左右のゆったりした半袖だけが淡青の半透明オーガンジーで、普通の上腕がうっすら見える。袖口は細い不透明の青い縁。胴体から肌・インナーの形・肩紐が一切透けない。首元は通常の丸首で鎖骨下まで覆う。裾はパンツのウエストに重なり、お腹が出ない。

## 02 抱っこ当然猫・袖の小窓

まんまるのガラス猫、横に張った太い頬、低い小さな耳。上まぶたがゆるい斜めで半分閉じた細めの目、離れ気味の小さい黒青い瞳。太すぎない短い眉を片側だけ少し上げ、むにっとしたへの字寄りの猫口。胸を張っていなくてもどこか偉そうで図太い。基本ポーズはどっかり座って短い両前足を「運んで」と伸ばす。しっぽは短いしずく形。甘えている自覚がなく、抱っこされると当然という顔をする。

図太い甘えん坊。運ばれる気満々だが、大事な場面では一言だけ的確に言う。

衣装：Ｔシャツは首から裾まで完全に不透明な水青のスポーツ生地で、大きな青いビー玉渦プリントを残す。少し丸いゆったり袖の外側に、ビー玉の曲面を連想する太い弧の形の半透明パネルを１枚ずつ入れる。透ける部分は袖面積の４分の１ほどで、上腕だけ。袖の大部分、肩、胸、背中、脇腹はすべて不透明。首元は普通の丸首。裾はパンツのウエストを覆う長さ。

## 03 しらんぷり猫・透け模様を点在

ほぼ丸い青いガラス猫。片耳だけ横に寝る。ほっぺは下にぷくっと広く、目は重いまぶたの細いジト目、ほぼ横向きの短い楕円に小さい瞳。口は短い横線の中央がほんの少し曲がる程度。正面を見ず横目で何でも知っていそうな顔。普段は腹ばいで短い前足に頬を乗せているが、興味のある話では耳と太い巻き尾だけがこっそり立つ。優等生の笑顔やキラキラした巨大な目にしない。

興味なさそうな聞き役。話の結末が気になると、顔は平静なまましっぽだけ動く。

衣装：Ｔシャツは不透明な淡い青を基調にした、丸首のすっきりしたスポーツＴ。胴体の大きな渦プリントは維持し、胸・背中・肩・首元・脇腹は完全に不透明で裏地もある。ゆったりした袖の下半分と、パンツに重なるＴシャツの裾のごく下端だけに、小さい丸や弧の半透明窓を合計数個、まばらに配置する。透け面積は服全体の１割以下。袖の窓は普通の上腕がうっすら見え、裾の窓の下は青いパンツで肌は見えない。下着やインナーが浮き出ない。お腹が出ない着丈。
