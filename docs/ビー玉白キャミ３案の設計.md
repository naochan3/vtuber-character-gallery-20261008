# ビー玉・白キャミの重ね３案

直前の３案の内側だけを、白い不透明な日常のキャミソールへ変更する。幅広い肩と丸首のインナーを、細めの２本の肩紐とすっきりした上端へ。キャミソールの上端は外Ｔの首元より下に重なり、内側の丸首がのぞかない。

顔・髪・瞳・体型、外Ｔのゆったりした袖と大きい渦、腕の透け感、各パンツの色と丸い形、透明な裾帯、靴とポーチを維持する。

## 1 水青パンツと白キャミ

- 服：水青の薄い渦Ｔ、白い細めの肩紐のキャミソール、水青ショーツと白い波の切り替え・薄い裾帯。
- 設計意図：白い内側を日常のキャミソールへ変更し、首元へ内側の丸首がのぞかないすっきりした重ね方にする。
- 元のパンツ：水青の波ライン。

## 2 白パンツと白キャミ

- 服：水青の薄い渦Ｔ、白い細めの肩紐のキャミソール、白いショーツと水青の丸いポケット・薄い裾帯。
- 設計意図：白い内側を日常のキャミソールへ変更し、首元へ内側の丸首がのぞかないすっきりした重ね方にする。
- 元のパンツ：白い丸ポケット。

## 3 青紫パンツと白キャミ

- 服：水青の薄い渦Ｔ、白い細めの肩紐のキャミソール、柔らかい青紫の丸いショーツと白い曲線・透明な裾帯。
- 設計意図：白い内側を日常のキャミソールへ変更し、首元へ内側の丸首がのぞかないすっきりした重ね方にする。
- 元のパンツ：青紫の丸い裾。
