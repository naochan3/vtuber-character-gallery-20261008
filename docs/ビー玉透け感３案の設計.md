# 原案142のビー玉・透け感と全身のバランス３案

人物の正本は原案142。ラムネの２枚は服の薄い素材・重ね方、上がゆるく胴が短めで脚が見えるバランスの参考として扱い、髪と顔は引き継がない。

薄い外側の布に不透明なスポーツインナーを重ね、大きい渦を維持する。二重の丸首、太い袖口、短めの身頃、太もも丈のゆるいショートパンツ、見える脚、丸い靴で輪郭を作る。全身とミニキャラで腰と四肢の動きが読める比率を比較する。

## 1 渦を重ねるシアーＴ

- 服：薄い水青の短めシアーＴ、生成りの不透明インナー、青紫の太もも丈ショートパンツ。
- 設計意図：薄い外布に渦を重ね、二重の丸首と腰が読める丈で軽いスポーツの印象を作る。
- 動きの設計：外側の薄い裾と丸い袖が先に揺れ、不透明の内側は安定して見える。
- 配色：水青・濃青・青紫・生成り・銀灰。

## 2 シアー袖の短いトラック服

- 服：透ける半袖の短いトラック上着、濃青の不透明な渦インナー、水青の太もも丈スポーツショーツ。
- 設計意図：短い上着と不透明の渦インナーの重ね、袖の軽さと脚の見える丈で活動感を作る。
- 動きの設計：半透明の大きい袖と上着の前が先に揺れ、短い裾とポーチが追いかける。
- 配色：水青・濃青・青紫・生成り・淡い灰。

## 3 二重の丸首と軽い袖

- 服：不透明な渦Ｔの身頃、軽い半袖、二重の丸首、濃青のゆったりスポーツショーツ。
- 設計意図：不透明な身頃に大きい渦を残し、軽い袖と二重の丸首で素材の違いを見せる。
- 動きの設計：軽い広い袖が先に揺れ、短い裾とポーチが小さく追いかける。
- 配色：水青・濃青・生成り・青紫・銀灰。
