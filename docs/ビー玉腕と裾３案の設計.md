# ビー玉・腕と裾の透け感３案

人物の正本は原案142。ラムネの参照は服の薄さとゆるい半袖の量感だけに使う。顔・髪・瞳は原案142を維持する。

腕の肌色と輪郭、外袖の輪郭、布と腕の間の空間の３つを描く。袖の中に別の衣服の袖を重ねず、胴は不透明な袖なし丸首シャツで覆う。透明感を光沢だけに置き換えず、腕の重なる部分と空間の色の違いを示す。

ショーツの本体は不透明。裾へ細い透明な帯を縫い足し、下に自然に見える脚との重なりを使って素材を伝える。ビー玉の流線・丸い波・浅い円弧を裾の形に使い、袖と同じ素材で一貫させる。

## 1 腕が見えるだぼっと袖

- 服：薄い水青の渦Ｔ、不透明な生成りの袖なし丸首インナー、青紫のショーツと透明な丸い裾帯。
- 設計意図：広い袖の空間と腕の肌色を同時に見せ、ショーツの丸い裾帯にもガラスの透明感を使う。
- 動きの設計：だぼっとした袖が腕から少し遅れて揺れ、裾の薄い帯とポーチが追いかける。
- 配色：水青・濃青・青紫・生成り・淡い灰。

## 2 波の裾とシアーシャツ

- 服：小さい丸襟の薄い水青シャツ、不透明な濃青の袖なし渦インナー、水青ショーツと波形の透ける裾。
- 設計意図：薄いシャツの腕まわりと、ビー玉の流れに沿う波形の裾をそろえた一貫した素材設計。
- 動きの設計：広い袖とシャツの前が先に揺れ、波形の薄い裾が短く追いかける。
- 配色：水青・濃青・青紫・生成り・銀灰。

## 3 丸い袖とクリアな裾

- 服：だぼっとした水青の薄いトップス、濃青の不透明な袖なし渦シャツ、丸い青紫ショーツと透明な裾帯。
- 設計意図：薄い丸い袖と、ショーツの浅い円弧の裾帯で、腕と脚の重なりから透明感を伝える。
- 動きの設計：丸い袖が少し広がって戻り、浅い円弧の裾帯と丸いポーチが小さく揺れる。
- 配色：水青・濃青・青紫・生成り・銀灰。

動きは設計ラフ。制作時は、腕、薄い袖、袖の輪郭と影、不透明なインナー、ショーツ本体、薄い裾帯を別のパーツとして分割・補完・リギングする。
